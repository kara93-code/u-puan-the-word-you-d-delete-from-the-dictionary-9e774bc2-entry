A one-word entry for make.fun's "The Word You'd Delete From the Dictionary" bounty. The word is **no** — erase it and nobody can refuse, deny, or disagree with anything ever again: every request gets a yes, every argument loses its favourite answer, and the language itself loses the power to say no.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3, standard library only) writes that one word to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`), exactly two bytes, no trailing newline, mode 0644. It writes nothing inside the repository.
